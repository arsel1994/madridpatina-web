# MADRIDPATINA · Hockey línea

Web del club para jugadores y familias: jornada, equipos, ligas, partidos, jugadores e histórico.

- Web: https://arsel1994.github.io/madridpatina-web/
- Datos: actas de la Federación Madrileña de Patinaje. Se actualiza sola cada semana, después del scraper.
- Sin fotos de menores y sin la edad de los menores.

Este repositorio solo contiene la web ya generada (HTML, CSS, JS y dos JSON). No se edita a mano: es del proyecto `fmp_better_scout_beta`.
